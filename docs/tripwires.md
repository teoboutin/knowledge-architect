# Tripwires — knowledge-architect

Evidence that would reopen a decision of `register@knowledge-architect@design`. A tripwire is
not something to do: it is a hypothesis about a future failure plus the response, and it leaves
this file by an exit of `skill@knowledge-architect-issue-tracking@movement-instruction`. What is outstanding about the project is
`register@knowledge-architect@issue`.

## Guarding `design@knowledge-architect@platform-skips`: a review of a branch meets a test left out for convenience `##a-product-test-left-out-on-a-system`

**Fires when:** an audit, an issue, or the review of a branch that did not add the mark, finds on main a
test of product behaviour that a system leaves out, or a case of one, which neither of the head's two
kinds admits, whatever reason or issue stands beside it.
**Response:** repair the test, and reopen the decision on what holds it: a check that lists each mark
with its kind, in place of the review alone.
**Re-entry:** the standing-state axis of a review before a merge, over
`git grep -nwE 'unix|windows|target_os|target_family|target_vendor' -- '*.rs'`, a lead: a condition in
`cfg`, `cfg_attr` or `cfg!`, on one line or broken over several, names a system by one of these words, and
so do product code and prose.
**Watches until:** the fifth commit on main, after the one that wrote this entry, that
`git log --oneline -G'(^|[^A-Za-z0-9_])(unix|windows|target_os|target_family|target_vendor)([^A-Za-z0-9_]|$)' -- '*.rs'`
lists. A commit that changes such a line of product code or of a comment counts too.
