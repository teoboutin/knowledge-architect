# Do the root's goals about the model, the tools and the checker belong in an intermediate Component?

## Summary

The owner states no purpose below the root for the Components split from the core, so
`design@knowledge-architect@no-intermediate-component` stands. The owner raised, as something that can
wait, moving a few of the root's goals about the model, the tools and the checker to an intermediate
level, if the root's goals grow too many with goals on these.

## Details

### What

Whether those goals state a purpose several Components serve together, which an intermediate Component
would then state in its goals home.

### Why it matters

An intermediate Component exists where a purpose is stated, per
`design@agent-skills@intermediate-component-occasion`, so moving the goals would reopen the head of
absence.

### What would close it

The owner's ruling at a review of the whole goal set, under `skill@knowledge-architect-goal-setting`.
