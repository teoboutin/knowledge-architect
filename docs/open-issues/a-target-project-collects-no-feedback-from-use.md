# A target project whose goal is judged in use collects no feedback from that use

## Summary

Rule 6 of the goal standard measures a goal whose outcome is judged only in use by what the project
builds to pursue it and to learn from its use whether it is met. The setup skill asks a target
project for nothing that collects feedback from its users, so such a project has, by default, no
route by which that use reaches it.

## Details

### What

The installed text names a route for agent-facing text, the retrospective, and none for a project's
own product: a channel by which its users' reports, or the observations of its owner in use, reach
its issues. The milestone that shipped the development skill decided to leave this to later work.

### Why it matters

A project's goal judged in use, such as a quality of its product only its users can see, is measured
by a mechanism the project does not build unless it thinks to, so the goal reads as met with nothing
learning whether it is. It strains `goal@knowledge-architect@the-workflow-improves-through-real-use`
by analogy only, since that goal ranges over the workflow itself.

### What would close it

A design session on what the setup skill asks of a target project for feedback from use, the shapes
it offers, and whether any of it is an ask, which goes to knowledge-architect's owner.
