# Rejected designs — xtask

The designs the Component xtask did not keep, each cited by the design heads of
`register@xtask@design` whose argument covers it. The designs not kept for how the gates run are
in `register@gates@rejected`.

### The source view of the shipped text as a subcommand of the checker `##source-view-in-the-checker`

`live`. The checker's command line is offered by every adopting project's binary, and the source
the view reads is this repository's alone. Such a command would either read the files of this
checkout, and find none in any other project, or embed every source with its `%%` comments, which
cite entries no other project holds, in every published binary.

### The source view exported from the agent-skills library `##view-exported-from-the-library`

`live`. On the owner's word, until the split of the agent-skills crate changes how the passes are
reached. An export joins the library API of a published crate, a surface whose every change
`design@knowledge-architect@versioning-policy` classes and
`design@knowledge-architect@changelog-entries` announces to consumers, for a function no consumer
calls.
