# knowledge-architect-transcript

The reader of the session transcripts Claude Code writes on disk: a project's sessions listed, shown or searched, each line labelled by what the harness recorded of it.

A project names the package [knowledge-architect](https://crates.io/crates/knowledge-architect) alone, whose binary offers
these commands and whose page says how to install and run it.
