# Goals

Every goal here serves one purpose: a session reads what the agent harness recorded of a project's past sessions, and knows what it could not read.

A session is one run of an agent in a target project. A tool here is something knowledge-architect publishes for a person or an agent working in a target project to run. The agent harness is the program a target project runs its agents under, whose record of each session it keeps on disk.

## A session reads what the agent harness recorded of a project's past sessions through one tool, each line labelled by what it holds, and is told what the tool did not recognise `##a-session-reads-past-sessions`

Where the workflow has a session consult past sessions, such as to review that a piece of work kept what its sessions established, and knowledge-architect's owner has taken that task in, the session reads them through a tool, with no script of its own. The tool says what each line is, from what the harness recorded of it. That reading is only as good as what the tool knows of the harness's format, which changes: so a form the tool does not know stops nothing, and the tool names it, and a session holding less is told from a tool that knows less.

It is met while, where that task is taken in, a tool lists, shows and searches the sessions of a project, tests show the label each kind of line gets and the report of a line no label takes, and the report asks that it reach knowledge-architect.

It refines `goal@knowledge-architect@agents-get-a-complete-workflow`.

- Requires, for instance: a line of a form the tool does not know is reported, and the run goes on.
- Admits, for instance: a tool that reads one harness alone; a list of sessions across every project on demand.
- Rules out, for instance: labelling a line the owner typed by a phrase in its text.
