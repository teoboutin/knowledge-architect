# What the level of the entries admits

A path of no project here: `path@elsewhere@another-project/README.md`.

A path every Component holds: `path@*@README.md`.

A path under the plans directory: `path@plans@README.md`.

A register's home every Component holds: `register@*@design`.

A register's home under the plans directory: `register@plans@spec`.

The goals home: `register@goal`.

A path no Component holds, which the level admits and the resolver reports: `path@*@nowhere.md`.
