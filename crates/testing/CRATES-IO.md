# knowledge-architect-testing

What an extension's tests need to run the checker over a mock project, as the binary runs it.

A project that writes an extension of [knowledge-architect](https://crates.io/crates/knowledge-architect) adds this
package to its dev-dependencies. A project with no extension never names it.
