# Agent skills: design

Recorded intent for the text the checker installs: which skills and agents exist, how they are
named, and how they divide the work. Present tense, each decision carrying a slug, cited as
`design@agent-skills@<slug>`. The designs this Component did not keep are
`register@agent-skills@rejected`, each cited by the heads whose argument covers it.

**What belongs here:** a decision about the installed text that does not survive deleting this
component, and the rules of the published workflow, which this repository follows as an adopting
project does. How the checker installs and verifies the text, including the prefix that names the
installed files, is `design@core@owned-namespace-check`.

The heads are grouped by subject, one subdocument per subject, listed below. A subject heading
carries no decision; each decision is one level-three head below it.

- [The shipped set](shipped-set.md): what ships, how content/ is built into it, and what the shipped text may cite
- [How the installed text changes](how-installed-text-changes.md): what enters agent-facing text, and how a change to it is shaped
- [Intent and the owner's ground](owner-and-intent.md): what a head and the code each bind, and what the owner's word grounds
- [What earns a record](what-earns-a-record.md): which decisions and rejected designs are recorded, and how a subject splits
- [The record search](record-search.md): the agent that reads the record before the work, and how it grades
- [Premortems and tripwires](premortem-and-tripwires.md): which causes become tripwires, and how long they watch
- [How documents point at each other](documents-point.md): where a reference is written, and how a dangling one is repaired
- [Plan documents](plan-documents.md): specs, milestones and the roadmap
- [Reviews](reviews.md): the review before a merge and its axes
- [The audit method](audit-method.md): what an audit is, how a pass runs, and what it leaves
- [The design-record and tripwire axes](audit-record-axes.md): the two axes that re-apply the record's rules entry by entry
- [The agentic-workflow axis](audit-workflow-axis.md): the axis that reads every instruction a session receives, and how its repairs are made
- [The configuration a project holds](project-configuration.md): the primer, and what a project's own configuration holds beside it
- [Goals](goals.md): the shape and the lifecycle of a goal
- [The retrospective](retrospective.md): the retrospective and its intake
