# No saved workflow runs the record search, which the owner takes in

## Summary

A session that runs the record search dispatches every searcher, checks each report and gathers
the verdicts by hand. A session of this repository ran the 36 searchers of a design audit as a
dynamic workflow instead, each agent in its own worktree. The owner took in the generic part of
that workflow at the intake of forty-seven files, and reports having plans for its design.

## Details

### What

- The search's dispatch is the record searcher's description,
  `path@agent-skills@content/agents/record-searcher.md`, per
  `design@agent-skills@one-record-searcher`. The installed text ships saved workflows for the
  audit axes alone, per `design@agent-skills@audit-axis-runs-a-workflow`.
- The report: the standing answers of the workflow file of the first slice of plan directories,
  2026-11-13, a workflow running a design audit's 36 searchers. Analysed in the section on the
  tools and procedures the batch reports, in `path@knowledge-architect@docs/retrospective-reports/2026-11-12-knowledge-architect-finding-repairs-klarch-workflow.md`, where the owner ruled it taken in.
- Bearing on it: `issue@agent-skills@no-test-runs-a-saved-workflow-s-logic`, which a saved
  workflow for the search would widen, and the subject `searcher-dispatch-exceeds-harness-cap` of
  the same intake, whose rewording of the dispatch sentence is the rival this workflow would
  replace.

### Why it matters

Each search dispatches up to 27 agents by hand and checks their reports one by one; a saved
workflow is a task a tool does better, per `goal@tasks-a-tool-does-better-are-the-tool-s`, and
the owner's choice takes its generic part in, per `goal@generic-tools-and-procedures-are-shipped`.

### What would close it

workflow shipped by the installed text with what the design decides about testing its logic.
