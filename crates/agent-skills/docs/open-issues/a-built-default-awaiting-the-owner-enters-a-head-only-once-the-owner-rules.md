# A built default awaiting the owner enters a design head only once the owner rules, where the owner wants agents more autonomous

## Summary

`skill@knowledge-architect-decision-recording@when-recording-happens` writes a default awaiting the
owner into a design head only once the owner rules on it. The owner wants that condition changed so
that agents are more autonomous about design, defaults and records, and more of the owner's intent
moves into goals. No discussion has decided how.

## Details

### What

The owner's ruling at the retrospective intake of 2026-10-24, on a rootpoint session that worked
six slices of a milestone in one branch: a built default narrowed a head while it awaited the owner,
and the owner wants to change the condition "A default awaiting the owner is built as written … and
enters a design head once the owner rules on it". The analysis read the case against the planning
skill's sentence that "A scope change listed there does not start before its ruling", which the
session had not applied, and against
`issue@agent-skills@the-primer-s-divergence-paragraph-reads-two-ways-on-work-that-goes-on`, whose
question the case answers in real use.

The work that opened this entry answered the other cases of the same intake: an
approval of the session's default at a fork is recorded as the session's choice, per
`design@agent-skills@fork-choice-in-weak-form`. It kept this condition, on the reading that the
owner's ruling decides when a head is written, not what it stands on; the owner has not ruled on
that reading.

Re-entry point: a design discussion under `skill@knowledge-architect-design`, on the owner's word.

### Why it matters

Every default held for the owner's word before it enters a head keeps a branch's record incomplete
until the ruling, against `goal@knowledge-architect@agents-work-without-drift`; a default written
into a head before the ruling records as settled what `goal@knowledge-architect@design-with-agents-as-counterparts`
asks the owner to meet before the merge.

### What would close it

A discussion under `skill@knowledge-architect-design` on when a built default awaiting the owner
enters a head, its outcome recorded in
`skill@knowledge-architect-decision-recording@when-recording-happens` and in the head that argues
it, or the owner's word that the condition stays as it is.
