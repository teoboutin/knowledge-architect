# knowledge-architect-create

Creates a knowledge-architect project and adds a Component to one: the manifest, the installed agent files, and the documents and homes the check requires.

A project names the package [knowledge-architect](https://crates.io/crates/knowledge-architect) alone, whose binary offers
these commands and whose page says how to install and run it.
