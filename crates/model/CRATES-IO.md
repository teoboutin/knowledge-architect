# knowledge-architect-model

What knowledge-architect reads of a project: its manifest, the walk git supplies, the parse of each
document, the entity table over them, and what a reference resolves to. It holds phases 1 to 3 of
the checker, which say whether the model can be trusted.

The checker, the package `knowledge-architect`, depends on it; a project names that package alone.
